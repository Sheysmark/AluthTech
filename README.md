# Aluth Tech Android App
WebView app for https://aluthtechfeed.blogspot.com/ (logo colors: #1A1A1A / #01E9FF).

## Build option A - Android Studio
Open this folder in Android Studio -> wait for Gradle sync -> Build > Build APK(s).
APK: app/build/outputs/apk/debug/app-debug.apk

## Build option B - GitHub (no PC tools needed)
Upload this folder to a new GitHub repo -> Actions tab -> "Build APK" -> download artifact "AluthTech-APK".

To change the website URL edit `homeUrl` in MainActivity.kt.
